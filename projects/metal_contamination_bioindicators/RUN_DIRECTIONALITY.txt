================================================================================
WHAT THE SCRIPT DOES
================================================================================

1. LOADS DATA:
   - analysis_matrix.parquet (187,755 × 538): USA samples with CLR values
   - redox_proxy.parquet: p_oxic_5m_proxy measurements
   - mwas_results.parquet: Top-40 MWAS genera by weighted_rho
   - sample_covariates.parquet: study_id for grouping
   - usa_rf_env_targets_rho.parquet: Pre-computed reverse direction ρ values

2. FILTERS TO USA BOUNDING BOX:
   - Latitude: 24°N to 50°N
   - Longitude: -130°W to -65°W
   - Result: 64,259 samples

3. COMPUTES FORWARD DIRECTION (env → microbiome):
   a) Standardizes 9 environment variables:
      - Geographic: lat, lon
      - Soil: sg_pH, sg_clay, log(sg_SOC+0.01)
      - Redox: p_oxic_5m_proxy
      - Metals: s25_as_AT, s25_cr_AT, s25_ni_AT
   
   b) For each of 35 MWAS genera:
      - Computes Spearman ρ between env features and genus CLR
      - Records per-genus correlation strength
   
   c) Computes CLR PC1:
      - PCA on top-40 MWAS genera CLR values
      - Computes Spearman ρ between each env variable and PC1
      - Reports individual and mean ρ values

4. LOADS REVERSE DIRECTION (microbiome → env):
   - From usa_rf_env_targets_rho.parquet (clr_only feature set)
   - 10 environment targets with Random Forest ρ values
   - Mean reverse ρ: 0.450

5. COMPUTES ASYMMETRY METRICS:
   - Directionality Index: (ρ_forward - ρ_reverse) / (ρ_forward + ρ_reverse)
   - Asymmetry (Δ): ρ_forward - ρ_reverse
   - Groups by variable type: Geographic, Soil, Redox, Metals

6. OUTPUTS JSON WITH:
   - forward_rho: per-genus correlation values
   - community_pc1_forward: PC1 correlation strength
   - reverse_rho: environment variables (RF-derived)
   - asymmetry_by_var: per-variable indices and asymmetries
   - group_summary: grouped metrics
   - genus_asymmetry: top genera analysis

================================================================================
INTERPRETING THE RESULTS
================================================================================

DIRECTIONALITY INDEX (DI):
  DI = (ρ_forward - ρ_reverse) / (ρ_forward + ρ_reverse)
  
  DI < -0.5:  Microbiome REFLECTS environment (microbiome is sensor)
  -0.5 < DI < +0.5:  Roughly symmetric coupling
  DI > +0.5:  Environment PREDICTS microbiome (environment drives composition)
  
  Interpretation: Negative DI means you can predict environment FROM
  microbiome better than you can predict microbiome FROM environment.

ASYMMETRY (Δ):
  Δ = ρ_forward - ρ_reverse
  
  Δ < -0.3:  Very strong asymmetry (reverse is much stronger)
  -0.3 < Δ < -0.1:  Strong asymmetry
  -0.1 < Δ < 0:  Moderate asymmetry
  Δ > 0:  Forward is stronger than reverse (rare in this dataset)

KEY FINDINGS FROM THIS ANALYSIS:
  
  ✓ Strong asymmetry (DI = -1.27): Microbiome is environmental sensor
  ✓ Soil properties dominate (DI = -2.03): pH and clay drive composition
  ✓ Geographic signal is moderate (DI = -0.75): Location correlates with niche
  ✓ Metal effects are weak: No strong linear correlations with PC1
  ✓ Redox signal is weak: May need non-linear modeling or higher resolution

================================================================================
TROUBLESHOOTING
================================================================================

Q: Script is running slow?
A: Spearman correlation on 64K samples × 35 columns should take <20s.
   If longer, check system load or RAM availability.

Q: Different results on re-run?
A: Results should be deterministic (no random elements).
   Check that data files haven't changed.

Q: JSON file is smaller/larger than expected?
A: File size depends on how many genus_asymmetry entries are included.
   Current output includes top-20 genera (can adjust in script if needed).

Q: Why are some forward correlations negative?
A: Spearman correlation is bidirectional; negative values mean genus
   abundance DECREASES as environment variable increases.
   This is normal and informative (opposite ecological niches).
